  Reordered display dimensions do not establish a different source file.

  `36bacf7541541613c3c937f7ce135f3c3dab427d3a9c5434b50a8f64458e33c9`.

## Allen Annotation Identity

The deployed `annotation.npy` has SHA-256
`8cd42d0f72ae4e2fb3eea35736b907ae8a64c46b04e95dcf9d803c7df39a7c44`.
It is a 528 x 320 x 456 uint32 array at 25 micrometers and is elementwise equal
to the fresh [official CCF 2017 annotation](https://download.alleninstitute.org/informatics-archive/current-release/mouse_ccf/annotation/ccf_2017/annotation_25.nrrd).
That downloaded NRRD has SHA-256
`c620cbcc562183e4dcd40250d440130501781f74b41de35b1c1bdabace290c42`.

The old registration summary references a different container and label encoding:
the [publication/transgenic-grid annotation](https://download.alleninstitute.org/publications/allen_mouse_brain_common_coordinate_framework/transgenic_lines_25_um_grid/ccf/CCFv3_annotation_25.nrrd).
Its fresh official download and retained local NRRD are byte-identical, SHA-256
`6f51f58b457e10c5889b5ce0df287ce82c3004d98f462a75d5c61705cd32d18d`.
Do not substitute this raw integer array for the ontology-ID array in the planner.

The two decoded arrays differ at all 32,387,385 nonzero voxels, while their
nonzero support is identical. This is not merely compression/header variation.
The publication file uses ordinal label indices; the current file uses ontology
IDs. The [official label table](https://download.alleninstitute.org/publications/allen_mouse_brain_common_coordinate_framework/transgenic_lines_25_um_grid/ccf/CCFv3_annotation_OntologyColor_labels.txt)
and the retained ontology resolve 663 of the 671 present labels by exact acronym.
The first strict-acronym check failed for eight names and remains archived.

An explicitly separate follow-up allows only a unique ontology match after
case folding and removal of non-alphanumeric characters for unmatched names:

| Publication acronym | Ontology acronym | Ontology ID |
| --- | --- | --- |
| CUL4 5 | CUL4, 5 | 1091 |
| Mmme | MMme | 732 |
| VISl23 | VISl2/3 | 973 |
| VeCb | VeCB | 589508455 |
| Mml | MMl | 606826647 |
| Mmm | MMm | 606826651 |

The resulting mapping is one-to-one for all 671 present labels. Applying it in
memory yields zero differences across all 77,045,760 voxels. No source file,
profile array, frozen manifest or experiment result was changed. Raw file hashes
remain different. This resolves the encoding difference, not MRI alignment or
the missing historical registration replay.

## Allen Terms And Delivery

Allen content is governed by the [Allen Institute Terms of Use](https://alleninstitute.org/legal/terms-of-use)
and [Citation Policy](https://alleninstitute.org/legal/citation-policy), including
research/noncommercial use and redistribution conditions. Keep source-specific
notices and attribution; do not apply ProbePlanner's MIT license to Allen data.

Any public runtime package must separately bind its actual annotation, MRI,
masks, SDF, surfaces and derived metadata. Preserved historical paths/hashes are
provenance identities, not interchangeable deployment inputs. Public metadata
projections must carry new hashes and must not upgrade registration confidence.

declared ready. No data upload is authorized by this audit document alone.
