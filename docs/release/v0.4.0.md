# ProbePlanner v0.4.0

This maintained software release is separate from the frozen
[`v0.3.0-paper` release](https://github.com/Shark04468/probeplanner/releases/tag/v0.3.0-paper).
The paper tags, version DOIs and archived results are unchanged.

## Changes

- A read-only CCF+MRI research viewer with a separately verified display
  package. It cannot generate or export a plan.
- A low-memory notice and serial processing of heavy display requests when
  startup headroom is low, without reducing the data resolution.
- Local application startup that binds the browser to its own backend session.
  The UI identifies planning and research sessions and shows profile hashes.
- Byte-preserving downloads of saved replay records. The audit download is
  separate from the existing `.pplan` and `.txt` geometry exports.

## Verification and limits

The application upgrade passed local Windows and Linux regression checks.
In the Linux live check, a fresh CA1/CA3 request covered both targets with one
selected probe. The replay JSON matched the saved record byte for byte, and
both geometry formats downloaded successfully. The separate research viewer
loaded all 810 scheduled meshes for its test profile and passed 18 slice
comparisons. These observations are software checks for those runs, not
independent anatomical validation, native-space surgical safety, or new paper
experiments. The optimizer source is unchanged.

## Install

Follow the [application startup guide](../APP_STARTUP.md). Obtain the matching
verified deployment profile separately; no MRI or atlas package is bundled.
The prebuilt UI asset is optional and can be extracted into `apps/ui/`; it
contains the `build/` directory. The Python backend is still required. This
release does not include a desktop installer. Review replay files for local
paths before sharing them.
